# Machine Learning

Este repositório tem o objetivo de organizar os projetos realizados durante a disciplina de Machine Learning. Foram desenvolvidos três projetos, abordando diferentes técnicas e algoritmos de aprendizado de máquina.

## Estrutura do Repositório

- ```Trabalho 1/``` - Aprendizado Supervisionado: Classificação de pacientes com diabetes com base em diversas features.
- ```Trabalho 2/``` - Aprendizado Não Supervisionado: Agrupamento de páginas do Facebook de varejistas de moda e cosméticos tailandeses para identificar padrões.
- ```Trabalho 3/``` - Aprendizado Profundo: Classificação de imagens para diferenciar imagens reais das geradas por inteligência artificial.
- ```README.md``` - Este arquivo contendo informações sobre o repositório.

## Tecnologias Utilizadas
- Python
- Bibliotecas: NumPy, Pandas, Scikit-Learn, Matplotlib, etc.
- Jupyter Notebook / Google Colab 

##  Trabalhos

🔹 Trabalho 1 - Aprendizado Supervisionado
O objetivo desse trabalho era construir um modelo de classificação para prever se os pacientes tinham diabetes com base em diversas features.

🔹 Trabalho 2 - Aprendizado Não Supervisionado
O conjunto de dados contém páginas do Facebook de 10 vendedores de varejo de moda e cosméticos tailandeses. O objetivo era agrupar as informações em alguns grupos distintos e analisar as características de cada um.

🔹 Trabalho 3 - Aprendizado Profundo
O objetivo desse trabalho era classificar imagens de um dataset para diferenciar aquelas criadas por inteligência artificial das imagens reais, utilizando redes neurais profundas.
